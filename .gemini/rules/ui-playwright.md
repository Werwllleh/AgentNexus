# Mandatory Visual Verification via Playwright

Любые изменения в визуальной части (UI, верстка, компоненты, стили CSS/Tailwind, модальные окна, сайдбары, списки, кнопки, отступы, адаптивность) **ОБЯЗАТЕЛЬНО И ВСЕГДА** должны проверяться в реальном браузере через Playwright:
1. Замер геометрических размеров элементов (`bounding_box()`, проверка на отсутствие сжатия контейнерами до 0–30px).
2. Проверка видимости и переполнения (`is_visible()`, отсутствие скрытия элементов скролл-контейнерами и перекрытий z-index).
3. Проверка Desktop (1280x800) и Mobile (390x844) разрешений.
4. Снятие скриншотов подтверждения.
5. Запрещено одобрять или завершать задачи без фактического запуска Playwright.
