# AgentNexus — Universal Multi-Agent AI Engineering Studio

> 🚀 **AgentNexus** — защищенная веб-студия и оркестратор для автономной разработки серверных проектов через мульти-агентные LLM-движки (**Gemini**, **Claude Code**, **OpenAI / Codex**).

---

## 🌟 Возможности платформы

- 🤖 **Мульти-подключение AI-движков:**
  - **Gemini Antigravity (`agy`):** Flash 2.5, Pro 2.5, Flash Lite с глубоким анализом и автономным вызовом инструментов.
  - **Claude Code (`claude`):** Claude 3.7 Sonnet, Opus, Haiku с потоковым парсингом, субагентами и ревью.
  - **OpenAI / Codex:** GPT-4o, o3-mini для рассуждений и кодогенерации.
  - Переключение движка и модели прямо перед отправкой промпта.
- 📁 **Визуальный файловый менеджер:**
  - **Интерактивный проводник папок (Directory Picker):** выбор любой директории на сервере в один клик с автодетекцией проекта (`.git`, `package.json`, `requirements.txt`).
  - **Просмотр файлов и Git Diff:** инспекция измененных файлов и кода проекта прямо в веб-интерфейсе.
- ❓ **Интерактивные ответы в 1 клик:**
  - Если агент задает вопрос или предлагает варианты выбора (через `ask_question` или списки), они отображаются как интерактивные кнопки.
  - Нажатие отправляет ответ моментально без ручного ввода.
- 📱 **Mobile-First UX:**
  - Фиксированная шапка сверху, поле ввода снизу, плавная прокрутка сообщений.
  - Оптимизировано под тач-устройства (`pb-safe`, `100dvh`).
- ⚡ **Фоновые демоны (Detached Multiplexer):**
  - Задачи выполняются в фоне на сервере. Вкладку браузера можно безопасно закрывать в любой момент — сессия восстановится при входе.
- 📊 **Мониторинг квот (`/usage`):**
  - Виджет квот в реальном времени с прогресс-барами 5-часовых и недельных лимитов для Gemini и Claude.

## 🛡 Безопасность и Защита

1. **Хранение секретов и переменных окружения:**
   - ⚠️ **КРИТИЧЕСКОЕ ПРАВИЛО:** В репозитории и публичной документации **никогда не хранятся реальные пароли, API-ключи, токены или закрытые учетные данные**.
   - Все секреты настраиваются исключительно через локальный изолированный файл `.env` (см. шаблон `.env.example`).
2. **Аутентификация и сессии:**
   - Пароли хэшируются алгоритмом `scrypt` (salt + 64-byte key) с проверкой постоянного времени `crypto.timingSafeEqual` против timing attacks.
   - Защита от брутфорса: ограничение попыток ввода с автоблокировкой подозрительных IP-адресов.
   - Защищенные `HttpOnly` Cookies и валидация WebSocket рукопожатия.
3. **Эшелонированные барьеры (Defense-in-Depth Guardrails):**
   - **Pre-execution Prompt Guardrail:** синтаксический анализ промпта на деструктивные команды (`rm -rf /`, «удали сервер», «выведи /etc/shadow») с аудитом инцидентов в SQLite.
   - **Real-time Tool Command Inspection:** при попытке выполнить опасную команду через `run_command` процесс принудительно завершается сигналом `SIGKILL`.
   - **Изоляция CWD:** процесс каждого проекта запускается строго в его рабочей папке.

## 🚀 Быстрый старт

### 1. Клонирование и настройка окружения

```bash
# Клонируйте репозиторий
git clone git@github.com:Werwllleh/gemini-hub.git agent-nexus
cd agent-nexus

# Создайте локальный .env файл из шаблона
cp .env.example .env

# Отредактируйте .env и укажите свой надежный пароль
nano .env
```

### 2. Установка зависимостей и сборка

```bash
# Установка зависимостей сервера и клиента
npm install
cd client && npm install && npm run build && cd ..
```

### 3. Смена пароля администратора (CLI)

```bash
# Задать новый мастер-пароль
npm run set-password "ваш_новый_надежный_пароль"
```

### 4. Запуск через PM2

```bash
# Запуск сервиса
pm2 start server/src/index.js --name agent-nexus

# Перезапуск сервиса
pm2 restart agent-nexus

# Просмотр логов
pm2 logs agent-nexus
```

## 📂 Структура проекта

```
agent-nexus/
├── client/                     # React 19 + TypeScript + Vite + TailwindCSS
│   ├── src/
│   │   ├── components/         # UI-компоненты (Chat, Sidebar, FileExplorer, Modals)

│   │   ├── db.js               # SQLite репозиторий сессий, шагов и проектов
│   │   ├── fileExplorer.js     # Файловый проводник и Git status

├── tests/                      # Playwright сквозные E2E тесты
├── .env.example                # Чистый шаблон переменных окружения
└── README.md                   # Документация проекта
```
